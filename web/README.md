# Agri Tree Web

Agri Tree is a modern React + TypeScript front‑end powered by Vite and shadcn‑ui. It connects to the Node.js API at `http://localhost:3000` and displays end‑to‑end traceability for agricultural produce.

## Tech

- Vite
- React + TypeScript
- Tailwind CSS
- shadcn‑ui

## Development

```bash
# from the project root
cd web
npm install
npm run dev
# open http://localhost:8080
```

## Environment

Create a `web/.env` if you need overrides:

```
VITE_API_BASE=http://localhost:3000
VITE_API_KEY=dev-api-key
VITE_DEMO_MODE=true
```

## Scripts

- `npm run dev` – start Vite dev server
